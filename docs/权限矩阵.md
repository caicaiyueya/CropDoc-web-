## 角色关系

- **FARMER**：注册默认身份。
- **EXPERT**：FARMER 经管理员审核通过后升级，继承农户全部能力并扩展 GUIDE / 专业回答 / PRO 资料。
- **ADMIN**：平台管理员，拥有全部管理端接口；类级 `@PreAuthorize("hasRole('ADMIN')")`。

## 路径隔离

| 前缀 | 访问方 |
|------|--------|
| `/api/auth/**` | 匿名（改密除外） |
| `/api/user/**` | 登录用户（按 role 细分） |
| `/api/admin/**` | 仅 ADMIN |
