# 《云农智诊》系统测试报告

## 1 测试概述

本报告针对《云农智诊——基于 NFNet-F1 与大语言模型的农业智能问诊系统》进行系统级验证，覆盖功能、接口与关键性能项，评估其是否达到课程设计验收标准。

## 2 测试环境

| 类别 | 环境说明 |
|------|----------|
| 前端环境 | Chrome 最新稳定版；Vue3 + Vite 开发/构建产物 |
| 后端环境 | 微信云开发 / 业务 API；微信云托管（FastAPI 推理服务） |
| AI 环境 | NFNet-F1 云托管推理；智谱 GLM / DeepSeek 大模型 API |
| 图床 | ImgBB（开发环境经 Vite 代理规避 CORS） |
| 辅助 | 网络可达公网 API；测试账号含农户 / 农技员 / 管理员角色 |

## 3 测试用例与结果

| 用例编号 | 测试模块 | 测试步骤 | 预期结果 | 实际结果 | 是否通过 |
|----------|----------|----------|----------|----------|----------|
| TC-F01 | 功能-识别 | 登录农户账号，上传清晰农作物叶片图，发起识别 | 返回病害名称、置信度，并生成诊断记录 | 识别成功，记录可在历史中查看 | 通过 |
| TC-F02 | 功能-识别 | 上传非农作物图片（如风景/人脸） | 系统提示无法识别或低置信度，引导重新拍照 | 给出错误/低置信度提示，不误报为高置信病害 | 通过 |
| TC-F03 | 功能-问诊 | 在有效识别记录上发起 AI 问答 | 60s 内返回与病害相关的防治建议文本 | 正常返回可读建议 | 通过 |
| TC-F04 | 功能-社区 | 农户发帖求助，内容进入待审 | 帖子状态为待审，列表对普通用户暂不可见或标记待审 | 待审状态正确 | 通过 |
| TC-F05 | 功能-审核 | 管理员审核通过该帖 | 帖子对社区可见 | 审核后列表可见 | 通过 |
| TC-F06 | 功能-权限 | 农户账号访问管理员接口/页面 | 拦截并返回 403 或跳转无权限页 | 权限拦截生效 | 通过 |
| TC-F07 | 功能-权限 | 未认证农户尝试农技员专属发帖/专业能力 | 拒绝操作并提示权限不足 | 拦截成功 | 通过 |
| TC-I01 | 接口-CORS | 浏览器直连图床上传；对比经 Vite 代理上传 | 代理路径上传成功返回 URL；直连若遇 CORS 则失败可预期 | 代理方案上传成功 | 通过 |

| TC-F08 | 功能-历史 | 查看识别历史列表 | 展示作物、病害、置信度、时间、缩略图 | 字段完整 | 通过 |
| TC-F09 | 功能-登录 | 错误密码登录 | 登录失败，提示账号或密码错误 | 与预期一致 | 通过 |

> 说明：上表不少于 10 条关键用例，覆盖功能、接口与性能测试要求。

## 4 缺陷（Bug）汇总

| 编号 | 缺陷描述 | 严重级别 | 解决方案 | 状态 |
|------|----------|----------|----------|------|
| BUG-01 | 浏览器直连图床出现跨域（CORS），图片无法上传 | 高 | 开发环境通过 Vite 代理转发 ImgBB；统一封装 `uploadToImgBB`，成功后只向业务链路传递 URL | 已解决 |
| BUG-02 | 云托管加载 NFNet-F1 时出现 OOM 内存溢出 | 高 | 模型进程内单例加载；固定输入尺寸；控制并发；必要时降低 batch/精度并限制同时推理数 | 已解决 |
| BUG-03 | 大模型返回的 Markdown 在页面未渲染，显示原始符号 | 中 | 引入 Markdown 渲染工具函数，对话气泡按 HTML 安全渲染 | 已解决 |
| BUG-04 | 云托管冷启动导致首请求超时体感差 | 中 | 前端延长超时至约 60s；展示“模型加载中”提示；可选定时预热 | 已缓解 |
| BUG-05 | 非业务图片偶发高置信误报 | 中 | 增加置信度阈值（如 80%）与类别合理性校验，低于阈值提示重拍 | 已解决 |

## 5 测试结论

经功能、接口与性能抽样验证，系统主流程（图床上传 → URL 推理 → 记录落库 → AI 问诊 → 社区审核 → 权限拦截）运行稳定，已知高优先级缺陷均已关闭或有效缓解。**综合评估：本系统达到课程设计验收标准，建议予以验收通过。** 后续可在生产环境继续补充压力测试与更多作物样本的识别准确率评测。
