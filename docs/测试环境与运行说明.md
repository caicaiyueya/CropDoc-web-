## 1. 测试环境

| 项 | 版本 / 说明 |
|----|-------------|
| OS | Windows 10/11 |
| JDK | 17（Eclipse Temurin 17.0.20+） |
| Maven | 3.9.6 |
| Node.js | 22.x（前端构建） |
| 后端框架 | Spring Boot 3.2.5、Spring Security、MyBatis-Plus 3.5.6 |
| 测试框架 | JUnit 5、Spring MockMvc、Mockito（`@MockBean AiService`） |
| 测试库 | H2 内存库（`MODE=MySQL`），profile=`test` |
| 生产库 | MySQL 8，库名 `yunnongzhizhen`（集成测试不依赖本机 MySQL） |

默认管理员（应用启动 / 测试初始化）：`admin` / `Admin@123`

## 3. 本地业务运行（非测试）

### 3.1 数据库

```bash
# 在 MySQL 8 执行
mysql -u root -p < sql/01_create_database.sql
mysql -u root -p yunnongzhizhen < sql/02_schema.sql
mysql -u root -p yunnongzhizhen < sql/03_seed.sql
```

### 3.2 环境变量（敏感配置）

| 变量 | 说明 |
|------|------|
| `DB_USERNAME` / `DB_PASSWORD` | 数据库账号 |
| `JWT_SECRET` | JWT 密钥（足够长） |
| `DEEPSEEK_API_KEY` | DeepSeek API Key（仅后端） |
| `UPLOAD_BASE_PATH` | 可选，默认 `./uploads` |

或复制 `backend/src/main/resources/application-dev.yml.example` 为 `application-dev.yml`。

### 3.3 启动后端

```bash
cd backend
mvn spring-boot:run
# 默认 http://localhost:8080
```

### 3.4 启动前端

```bash
cd frontend
npm install
npm run dev
# 默认 http://localhost:5173 ，/api 代理到 8080
```

生产构建：

```bash
cd frontend
npm run build
```
