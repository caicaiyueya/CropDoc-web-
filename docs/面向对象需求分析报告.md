# 《云农智诊》面向对象需求分析报告（OOA）

## 1 文字分析

### 1.1 参与者与用例划分

从问题域识别三类主要参与者：**普通农户（Farmer）**、**农技员（Expert）**、**系统管理员（Admin）**。农户关注“拍照识别—查看结果—AI 问诊—发帖求助”闭环；农技员侧重“发布科普、解答疑问”；管理员负责“用户管理、帖子审核、病害库维护”。用例之间存在包含/扩展关系的潜力（如“查看结果”常包含在识别成功路径中），本报告以核心用例为主进行建模。

### 1.2 核心业务流程（活动视角）

“病虫害识别与智能问诊”活动以图片上传为起点：上传失败则提示重试；成功后调用推理；若置信度低于阈值（如 80%），提示重新拍照；否则展示结果并允许进入 AI 问诊，最终输出防治建议。该流程覆盖正常路径与异常/低置信度分支，适合作为验收的主场景。

### 1.3 领域类与关系

领域模型抽取四类核心实体：**User**、**DetectionRecord**、**Post**、**Comment**。通过特化体现农户/农技员/管理员继承自 User；User 与 Post、DetectionRecord 为一对多关联；Post 与 Comment 为一对多组合/关联。属性与方法聚焦业务行为（登录、识别、发帖、评论、审核），支撑后续类图到实现类的映射。

## 3 核心活动图（病虫害识别与智能问诊）

**文字解析**：活动图描述农户从上传到获取防治建议的控制流，含上传成败与置信度阈值两个关键判定；低置信度回流至重新拍照，保证识别质量，高置信度路径进入问诊形成完整业务闭环。

```mermaid
flowchart TD
  Start([开始]) --> Upload[农户上传叶片图片]
  Upload --> UOK{图片上传成功?}
  UOK -->|否| Tip1[提示重新上传]
  Tip1 --> Upload
  UOK -->|是| GetURL[图床返回图片URL]
  GetURL --> Infer[调用 NFNet-F1 推理]
  Infer --> Conf{置信度 ≥ 80%?}
  Conf -->|否| Tip2[提示重新拍照/换角度]
  Tip2 --> Upload
  Conf -->|是| Show[展示病害名称与置信度]
  Show --> Ask{是否进入 AI 问诊?}
  Ask -->|否| End1([结束:仅查看结果])
  Ask -->|是| Chat[组装上下文并调用大模型]
  Chat --> Advice[展示防治建议]
  Advice --> End2([结束])
```

**如何查看**：粘贴至 Mermaid Live；菱形为判定节点，圆角矩形为活动。

## 4 领域类图（Class Diagram）

**文字解析**：类图给出问题域静态结构：User 特化为三类角色；一名用户可产生多条诊断记录与多篇帖子；一篇帖子包含多条评论。方法反映用例驱动的职责分配，便于映射到实体层与服务层实现。

```mermaid
classDiagram
  class User {
    +String id
    +String username
    +String passwordHash
    +String role
    +String status
    +login()
    +updateProfile()
  }

  class Farmer {
    +detectDisease()
    +askAI()
    +createHelpPost()
  }

  class Expert {
    +publishGuide()
    +replyQuestion()
  }

  class Admin {
    +manageUsers()
    +reviewPost()
    +maintainDiseaseLib()
  }

  class DetectionRecord {
    +String id
    +String crop
    +String disease
    +float confidence
    +String imageUrl
    +DateTime createdAt
    +save()
    +getAdviceContext()
  }

  class Post {
    +String id
    +String title
    +String content
    +String tag
    +String status
    +DateTime createdAt
    +submit()
    +approve()
    +reject()
  }

  class Comment {
    +String id
    +String content
    +DateTime createdAt
    +boolean isProfessional
    +publish()
  }

  User <|-- Farmer
  User <|-- Expert
  User <|-- Admin
  User "1" --> "*" DetectionRecord : 产生
  User "1" --> "*" Post : 发布
  Post "1" --> "*" Comment : 包含
  User "1" --> "*" Comment : 撰写
```

**如何查看**：在 Mermaid Live 中渲染；`<|--` 表示继承，`"1" --> "*"` 表示一对多关联。
